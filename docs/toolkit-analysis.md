# Разбор тулкита тестировщика (agent-toolkit-shoporama) — что берём

> Владелец кинул пример тулкита тестировщика (QA/bug-coverage автоматизация для
> Shoporama) и попросил: посмотреть, есть ли что-то глобально/абстрактно применимое
> к Symbiont. Разбор 2026-07-30. Сама папка — временная, удаляется после разбора.

## Что это

QA-тулкит с чистой слоистой архитектурой: **atoms** (детерминированные Python-примитивы
домена: auth/login, popups/dismiss, recipients) → **scenarios/pipelines** →
**cubes** (одноцелевые агенты-`.md`, по одной ответственности) → **pools** (DAG-манифесты
оркестрации) → **orchestrator**. Плюс `.claude/` команды и скиллы (prod-db, opensearch,
sql-safety-check, findability).

## Что ПОДТВЕРЖДАЕТ наши аксиомы (независимое схождение, не новое)

- **harvest-knowledge cube** (в конце сессии извлекает переиспользуемые дельты новых
  атомов/ловушек/памяти, «дельта с именами файлов, не fyi») = наше «наполнение —
  побочный продукт» + садовник. Дисциплина «дельта с именами» — хорошая, у нас есть.
- **Само-защита каждого куба** («вызван напрямую мимо оркестратора → теряет
  семантику локов → каждый куб пробит-и-стоп, file-exists guard») = наш fail-open /
  crash-only / «никогда молча».
- **Идемпотентность везде** (`x-idempotent`, «render-regression-test никогда не
  перезатирает вручную-настроенный тест») = храповик + «ручное побеждает».
- **Острый набор одноцелевых кубов** (18 готовых, не зоопарк) = наша аксиома «острый
  набор ~10 надёжнее 100 перекрывающихся».
- **Слоистая композиция** (детерминизм внизу, агенты сверху) = слои 0/1/2.
- **«Never guess»** (`x-blocking-questions`: «стенд недоступен → inspection-needed, НЕ
  угадывай селектор») = наше «факты, не выдумки».

Вывод: тулкит независимо пришёл к тем же принципам — это валидация ядра Symbiont.

## Что берём НОВОГО (абстрактно, без хардкода) — 2 идеи

### 1. «Паспорт не врёт» — аудит против вейпорвара (findability-скилл)

Скилл `refactoring-toolkit-findability` бьёт в 4 причины «всё есть, но агент не
находит», и три из них — **прямо про наш паспорт как КАРТУ**:

- **«Карта врёт»**: вход-доки описывают несуществующую/полупустую архитектуру,
  роутят агента в мёртвые пути. → Паспорт Symbiont НЕ должен подавать вейпорвар:
  узел графа, которого уже нет; конвенцию, которая вытеснена, но всё ещё в сводке;
  «ключевой модуль», который удалён. Datomic-вытеснение + retractMissingBySource
  часть закрывают, но **отдельного инварианта «сводка = только живое» нет**.
- **Осиротевшие доки / findability**: у нас уже есть — entity-граф сироты (v0.43).
  Обобщение: findability самого ЗНАНИЯ паспорта.
- **Протухшая противоречивая память**: Glicko/FSRS + SimHash закрывают.

→ **Дополняет слой дрейфа** (`docs/drift-layer.md`): дрейф бывает не только кода, но
и **само-образа агента** — паспорт уползает от реальности (описывает то, чего нет).
«Аудит вейпорвара паспорта» = дешёвый детерминированный чек: каждый узел/факт сводки
резолвится в существующий файл/актуальный замер; расхождение → вытеснение + пометка.

### 2. Структурный само-линт (`validate.py`)

Тулкит держит `validate.py`: registry↔cubes↔INDEX консистентность, **закрытые enum'ы**
(неизвестное значение = красный), структурные инварианты (`isolation⇔WORKTREE`,
no-dual-resource, no-PURE-that-writes). Это **само-диагностика структуры**, а не
поведения.

→ У Symbiont есть канарейка (смок каналов процессами) и heartbeat (пульс каналов), но
**нет структурного само-линта**: каждый MCP-инструмент имеет схему? каждый скилл,
на который ссылаемся, существует? инвариант «сигналы определены ОДИН раз в signals.ts»
держится (не разъехались stack↔profile — прошлая находка аудита)? версии проекций
согласованы? Дешёвый dev-time (или разовый на SessionStart) чек — расширение аксиомы
живучести с каналов на структуру. Грех — молчание, не поломка; сейчас структурная
поломка молчит до первого падения.

## Что СОЗНАТЕЛЬНО НЕ берём

- **`x-` parallel-class + orchestrator + pools** (PURE/WORKTREE/SERIAL_SHARED/SINGLETON,
  мьютексы по shared-resource). Блестящая инженерия, но она про **оркестрацию роя
  агентов** — а у нас аксиома «писатель один», дорогое-по-триггеру, без постоянной
  мультиагентности. Мета-принцип «декларируй машинно-проверяемо то, что платформа не
  выражает нативно» мы уже применяем (heartbeat, signals, projection-version). Сам
  механизм локов — не наш профиль (мы не гоняем 16 параллельных мутирующих джобов).
- **Доменные atoms Shoporama** (login/popups/recipients) — хардкод под конкретный
  продукт; наш путь — выводить такое из проекта, не зашивать.

## Итог

Тулкит — сильное независимое подтверждение ядра Symbiont + две абстрактные идеи в
бэклог исследований: **(1)** аудит «паспорт не врёт» (в слой дрейфа — дрейф само-образа),
**(2)** структурный само-линт (в живучесть/само-диагностику). Обе — детерминированные,
дешёвые, языко-агностичные, без хардкода. `x-`-оркестрация осознанно отклонена
(конфликт с «писатель один»).
