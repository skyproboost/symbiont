Собирает один самодостаточный HTML-файл и сразу открывает его — узлы тянутся мышью, размер показывает, насколько модуль важен для проекта, свечение — что его недавно трогали, цвет — часть проекта, клик открывает роль файла и обе стороны его связей; есть поиск, зум и заморозка раскладки. Файл не делает ни одного внешнего запроса и не содержит ни строки исходного кода — только пути, связи и уже выведенные роли, поэтому открывается офлайн и ничего не разглашает. # Symbiont · интерактивная карта

!`bun run "${CLAUDE_SKILL_DIR}/../../src/cli/symbiont.ts" --data "${CLAUDE_PLUGIN_DATA}" graph $ARGUMENTS`

Карта открывается в браузере сама; путь к файлу тоже печатается — на случай, если открыть нечем (WSL, ssh, headless). Что там есть:

- **Размер узла** — важность модуля в графе: чем крупнее, тем больше от него зависит проект.
- **Свечение** — тепло: над этим файлом работали недавно. Остывает между сессиями.
- **Цвет** — зона проекта, кластеры видны глазами без всякой кластеризации.
- **Клик по узлу** — закрепляет его: показывается роль (если уже выведена фоном), важность, кто от него зависит и от чего зависит он.
- **Поиск** — подсвечивает совпадающие файлы, остальные приглушает.

Карта строится из уже посчитанных проекций и ничего не пересобирает. Роли узлов появляются по мере работы: фоновый садовник выводит их для тех файлов, которые действительно открывали.
